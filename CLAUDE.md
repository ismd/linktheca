# CLAUDE.md

## Описание проекта

Linktheca — это open source проект, который позволяет реализовать on-premise read-it-later workflow с мониторингом новостей. Сервис позволяет сохранять ссылки, статьи и другие ресурсы для последующего чтения. Помимо сохранения ссылок, Linktheca предоставляет мониторинг новостей по интересующим пользователя темам: пользователь указывает темы, а сервис автоматически находит релевантные новости и уведомляет об обновлениях. Для семантического поиска по темам используются embeddings, работающие локально без внешних API.

## Архитектура

Linktheca — один проект (монорепозиторий) с чистыми границами между модулями:
- **Read-it-later** — сохранение ссылок и управление ими. В UI — раздел **Library**, содержит только статьи, которые пользователь сам добавил.
- **Мониторинг новостей** — слежение за темами, семантический поиск (embeddings), уведомления. В UI — раздел **Radar**, содержит только статьи, найденные crawler'ом по подписанным темам.
- **Общее ядро** — парсинг контента, UI

Модули разделены на уровне пакетов/сервисов внутри одного репозитория. При необходимости мониторинг можно выделить в отдельный проект в будущем.

Важное UX-решение: **Library и Radar не смешиваются**. Пользовательские сохранения и автоматические находки живут в разных разделах, чтобы лента сохранённого не размывалась шумом от crawler'а.

## Прототип

Визуальный прототип UI находится в `prototype/index.html` — одностраничный HTML с hash-роутингом на Tailwind CDN. Используется для обсуждения дизайна и UX, не является частью продакшн-кода. Определяет визуальное направление (editorial/литературная эстетика, Fraunces + Newsreader + JetBrains Mono, warm paper + vermillion accent) и структуру основных экранов: Library, Radar, Topic view, Article reader, Settings.

## Техническая сторона проекта

Используемые языки программирования:
- Go для бэкенда
- TypeScript (React) для фронтенда
- Dart (Flutter) для мобильного приложения
